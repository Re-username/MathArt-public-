# MathArt

**Математическая артиллерия в киберпанк-стиле.** До 6 игроков стреляют друг в друга не снарядами, а графиками функций: пуля летит строго по кривой `y = f(x)`, которую ты написал. Чем хитрее формула — тем хитрее траектория.

## О игре

Каждый игрок управляет танком на общем поле. В свой ход ты вводишь уравнение — и пуля вылетает из твоего танка ровно по графику этой функции: параболы облетают препятствия «над горкой», волны `sin` огибают стены, гиперболы `1/(x−a)` резко уводят в сторону. Попади в соперника раньше, чем он попадёт в тебя. Последний выживший побеждает.

Есть режим **«мультиточки»** (как в GraphWar): у каждого игрока по 2–3 случайно расставленных танка, и в начале каждого своего хода ему выбирается другая случайная точка, от которой он будет стрелять. Два игрока по 3 точки выглядят на поле как матч 3 на 3.

## Возможности

**Режимы**

- ◎ **Разминка (соло)** — тренировка по мишеням; работают все механики, включая мультиточки;
- ▶ **Hot-seat** — 2–6 игроков за одним экраном, ходы по очереди;
- ⇄ **Сетевая игра (LAN/P2P)** — до 6 игроков по сети.

**Движок стрельбы**

- Поле `y = f(x)` или `x = f(y)` (кириллические `х`, `у` тоже работают);
- Обычный ввод (mathjs) или **LaTeX-режим** (`∑ LaTeX`): `y=\frac{1}{2}x^{2}+3`, `\sqrt{x}`, `\sin x + \pi` — с показом канонического вида;
- Два метода отсчёта координат: **Zero point** (ноль в твоём танке, кривая всегда через тебя) и **GW point** (абсолютные координаты карты, как в GraphWar);
- Предпросмотр траектории и предсказание точки финиша;
- Лимит колебаний против «пил» (высокочастотных синусов), защита от зацикленных маршрутов, проверка достижимости спавнов;
- Направление полёта: ◀ ▶ (или ▲ ▼ для `x = f(y)`).

**Механики попаданий**

- Жизни (1–5 попаданий до смерти);
- **Пробитие** — пуля поражает 1–6 игроков на линии;
- **Отброс при попадании** — выжившая жертва мгновенно смещается на случайную свободную клетку (радиус 1–10);
- **Мультиточки (1–3 точки у игрока)** — жизни у каждой точки отдельно: поразить можно любой спот (активный или приглушённый), подбитая точка исчезает, игрок воет с оставшихся; смерть — когда подбиты все. Работает в hot-seat, сети и соло;
- **Препятствия** — круги, квадраты, ломаные, кривые Безье; режимы разрушаемости: отключена / частичная (3 попадания) / полная (1 попадание) / **прогрызание** (пуля бурит сквозные отверстия);
- Командный режим: «каждый сам за себя», 2 на 2, 3 на 3 (огонь по своим отключён).

**Интерфейс и звук**

- Киберпанк-неоновая тема + светлая; компактный/средний/крупный интерфейс;
- Панель уравнения в 4 позициях, миникарта с зумом и панорамированием (колесо / перетаскивание / двойной клик);
- Синтвейв-саундтрек + звуковые эффекты; **своя музыка** из папки `music/` для всех игроков LAN-сервера;
- Чат в матче, история уравнений (свои / всех) с кликабельными записями;
- Таймер хода, настройки сохраняются в браузере.

## Быстрый старт

### Играть без сборки (релиз)

| Файл | Что это |
|---|---|
| `MathArt.html` | Вся игра одним файлом (~66 МБ). Двойной клик — и играешь, без установки и интернета. Сеть — через обмен WebRTC-кодами |
| `Запустить MathArt.bat` | Запускатель LAN-сервера для Windows: сам ставит Node.js при необходимости, скачивает зависимости, поднимает сервер и открывает браузер |
| `MathArt LAN-сервер.zip` | Исходники + батник + папка `music/` — для игры по локальной сети и своей музыки |

### Разработка

```bash
npm install            # первый раз, 1–3 минуты
npm run dev -- --host  # http://localhost:5173, виден в локальной сети
npm run build          # продакшн-сборка в dist/
npm run preview        # просмотр сборки
npm run lint           # проверка кода
```

**Требования:** Node.js 20.19+ или 22.12+ (рекомендуется LTS 22). Vite 7 на старых версиях Node не стартует. Браузер — любой современный (Canvas + WebSocket).

> ⚠️ `npm install` может вывести «N vulnerabilities» — это нормально, предупреждения относятся к инструментам разработки. **`npm audit fix` не запускай** — можно сломать сборку.

## Как играть

1. В свой ход введи уравнение в поле «Уравнение выстрела», например `y=0.5*x^2`.
2. Выбери направление полёта: ◀ ВЛЕВО / ВПРАВО ▶ (для `x=f(y)` — ▲ ВВЕРХ / ▼ ВНИЗ).
3. Предпросмотр покажет траекторию и точку финиша. Нажми **ОГОНЬ** (или Enter).
4. Пуля летит по графику. Попадание в игрока отнимает жизнь, попадание в препятствие — взрыв (или пробитие/разрушение/прогрызание — по настройкам).
5. Побеждает последний выживший (или команда в командном режиме).

**Управление:** Enter — выстрел · колесо — зум к курсору · зажатая ЛКМ — панорама · двойной клик / ⤢ — вся карта · F1 — справка.

### Мультиточки («Точек у игрока: 2–3»)

У каждого игрока N случайно расставленных точек-танков. Каждый ход игрок стреляет от другой случайной точки (она подсвечена пульсирующим кольцом, остальные приглушены). **Жизни у каждой точки отдельно**: любой спот можно поразить — активный или приглушённый, исчезает ближайшая к точке попадания; игрок продолжает с оставшихся и проигрывает, только когда подбиты все его точки. Хорошо сочетается с отбросом, пробитием и командными режимами.

### Точка отсчёта кривой («Логика стрельбы»)

- **Zero point** (по умолчанию, новый метод): ноль в твоём танке, кривая всегда проходит через тебя, сдвиг по горизонтали — через аргумент `f(x−a)`;
- **GW point** (старый метод): `x` — абсолютная координата карты, кривая вертикально сдвигается так, чтобы пройти через тебя. Удобен, если привык считать по сетке карты (как в GraphWar).

## Язык формул

Поле принимает `y=f(x)` или `x=f(y)`. Дробные числа — через точку (`0.5`, не «0,5»), умножение можно опускать (`2x`, `3sin(x)`), переменные латинские или кириллические.

| Группа | Функции |
|---|---|
| Тригонометрия | `sin cos tan asin acos atan sinh cosh tanh` |
| Корни и степени | `sqrt cbrt pow(x,3) x^2 x^(1/3)` |
| Модули и знаки | `abs sign floor ceil round` |
| Экспонента и логарифмы | `exp log ln log2 log10` |
| Прочее | `min max mod(x,5)` |
| Константы | `pi e tau` |

Примеры рабочих выстрелов:

| Уравнение | Эффект |
|---|---|
| `y=0.5*x` | прямая насквозь |
| `y=0.08*x^2` | парабола через танк — обстрел «над горкой» |
| `y=6*sin(0.25*x)` | волна — обход препятствий |
| `y=1/(x-5)` | гипербола с асимптотой — резкий уход в сторону |
| `x=3` | вертикальный выстрел |

Тонкости Zero point: свободный член поглощается (кривая всегда через танк — `y=x^2+5` летит как `y=x^2`), разрыв в нуле невозможен (`y=1/x` не выстрелит — смести асимптоту: `y=4/(x-5)`).

## Сетевая игра

Два транспорта, выбираются в меню «Сетевая игра»:

- **Простой режим (одна сеть, рекомендуется):** хост запускает игру через батник, друзья открывают его адрес (строка `Network` в окне батника) и вводят 4-значный код комнаты. Релей WebSocket крутится прямо на dev-сервере хоста — WebRTC не нужен.
- **Режим кодов (P2P, WebRTC):** хост создаёт комнату, гость передаёт код-предложение, хост отвечает кодом-ответа. Работает через интернет и из одиночного `MathArt.html`. Коды одноразовые. При жёстком NAT укажите TURN-сервер в настройках (бесплатный ключ — на metered.ca). VPN выключить, брандмауэр разрешить.

2–6 игроков; хост управляет матчем, реванш запускает хост. Рассылка позиций танков не требуется — состояние мира детерминировано (см. [Архитектура](#архитектура)).

## Своя музыка (только LAN-версия)

1. Положи аудиофайлы в папку **`MathArt/music/`** рядом с батником.
2. Форматы: **mp3, ogg, wav, m4a, flac**.
3. Перезапуск не нужен — сервер подхватывает треки сразу. Твои треки играют первыми, затем встроенные.
4. Музыка звучит у всех подключённых игроков — файлы раздаёт сервер хоста.

В одиночном `MathArt.html` функция недоступна (файл не может ничего раздавать по сети) — игра играет встроенные треки.

## Настройки матча

Настройки сохраняются в браузере (localStorage); в сетевой игре берутся у хоста лобби.

**Карта и ход:** размер карты · таймер хода (0 — без лимита) · разброс спавна, % · попаданий до смерти (1–5) · точек у игрока (1–3, мультиточки) · режим матча (FFA / 2 на 2 / 3 на 3) · предпросмотр траектории · предсказание финиша.

**Ограничения кривых:** лимит колебаний на единицу длины (0 — без лимита) · зацикленные маршруты · проверка достижимости спавнов.

**Логика стрельбы:** точка отсчёта кривой (Zero / GW point).

**Попадания:** игроков поражает пуля (1–6, пробитие) · отброс при попадании · радиус побега, клеток (1–10; в сети точка побега одинакова у всех).

**Чат и история:** чат в матче · история уравнений (свои / всех).

**Препятствия:** вкл/выкл · разрушаемость (отключена / частичная / полная / прогрызание) · типы (круги, квадраты, ломаные, Безье, замкнутые Безье) с количеством и размером каждого.

## Устранение неполадок

Краткая шпаргалка (полная версия — в [`Как установить и играть.md`](../Как установить%20и%20играть.md)):

| Проблема | Решение |
|---|---|
| Node.js не найден / не скачался | Поставь вручную: <https://nodejs.org> → LTS → перезапусти батник |
| `npm install` выдаёт vulnerabilities | **Норма**, это инструменты разработки. `npm audit fix` не запускать |
| Порт 5173 занят | Закрой лишние терминалы/IDE или запусти вручную: `npm run dev -- --host --port 3000` |
| Друг не видит сервер | Одинаковая сеть? IP из строки Network (не localhost)? Не гостевая сеть? Брандмауэр разрешил Node.js? |
| WebRTC не соединяется | TURN-сервер в настройках, VPN выключен, Chrome/Edge у всех; надёжнее — LAN-режим |
| Кривая «уходит в неопределённость» | Функция не определена в точке танка — смести аргумент: `y=sqrt(x+30)`, `y=1/(x-5)` |
| Музыка молчит | Кликни по странице (автовосплей блокирует браузер); треки из `music/` — только в LAN-версии |
| Рассинхрон в сети | У всех одна версия игры: F5 у всех и матч заново |

## Технологии

- **React 19 + TypeScript ~5.9** — интерфейс;
- **Vite 7** — сборка и dev-сервер;
- **Tailwind CSS 3.4** — стили, киберпанк-тема на CSS-переменных;
- **mathjs** — парсер и вычислитель формул (+ собственный конвертер LaTeX → mathjs);
- **WebSocket (`ws`)** — релей комнат на dev-сервере хоста;
- **WebRTC** — P2P-режим с ручным обменом SDP-кодами;
- Canvas 2D — отрисовка сцены, «прогрызание» отверстий в препятствиях.

## Архитектура

- **Детерминированность вместо рассылки состояния.** Позиции танков и препятствий не рассылаются: гости детерминированно повторяют выстрелы хоста, поэтому состояние мира сходится без рассинхрона. В sync-сообщениях — только `[id, hp, alive]`.
- **Мультиточки без изменения протокола.** Хост генерирует плоский массив позиций (число = игроки × K), гости группируют локально по `settings.pointsPerPlayer`. Активная точка выбирается детерминированно: `pickActiveIdx` (mulberry32 от `(shotNumber, playerId)`) — у всех клиентов одинаково, включая переключение после подбития активной точки.
- **Урон по точкам.** При попадании ищется ближайшая к точке удара точка жертвы — поразить можно любой спот; подбитая точка удаляется, `hp` игрока — сумма жизней оставшихся точек.
- **Отброс и пробитие.** Отброс считается на хосте и рассылается с выстрелом (`flee`), пробитие — флагом в траектории; пуля прозрачна для своих точек и взрывается о стены/препятствия.
- Релизный `MathArt.html` собирается `vite-plugin-singlefile` (+ скрипт инлайнинга ассетов и музыки в data URI).
