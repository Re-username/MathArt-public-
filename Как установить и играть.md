# MathArt — математическая артиллерия

Полное описание проекта: установка, запуск, устранение ошибок, правила игры и все настройки.

**MathArt** — киберпанк-игра-артиллерия на уравнениях: до 6 игроков, каждый управляет танком и стреляет кривыми `y = f(x)`. Пуля летит именно по графику функции — чем хитрее формула, тем хитрее траектория. Попади в соперника, пока он не попал в тебя. Есть режим «мультиточки» (как в GraphWar): у каждого игрока по 2–3 случайно расставленных танка, и каждый ход стрельба идёт от другого случайного.

---

## 1. Что в архиве

| Файл / папка | Назначение |
|---|---|
| `MathArt.html` | Вся игра одним файлом (~66 МБ). Двойной клик — и играешь. Не требует установки и интернета |
| `Запустить MathArt.bat` | Запускатель LAN-сервера (Windows). Ставит Node.js при необходимости, скачивает зависимости, поднимает сервер и открывает браузер |
| `MathArt LAN-сервер.zip` | Исходники игры + батник + папка `music/`. Распаковать и запустить батник — для игры по сети с друзьями и своей музыки |
| `MathArt/music/` | **Твоя папка с треками.** Кидаешь сюда mp3/ogg/wav/m4a/flac — они играют у всех игроков сервера |
| `MathArt/app/…` | Исходный код (React 19 + TypeScript + Vite 7 + Tailwind). Для запуска вручную или доработки |

Два способа играть:

- **Один файл (`MathArt.html`)** — быстро, локально, без сервера. Сетевая игра в нём работает через ручной обмен кодами (WebRTC), своя музыка — недоступна (файл не может раздавать треки).
- **LAN-сервер (батник из архива)** — полная функциональность: простое подключение друзей по коду комнаты и своя музыка для всех.

## 2. Установка и запуск

### Вариант А. Один HTML-файл (самый простой)

1. Скопируй `MathArt.html` куда угодно (можно на флешку).
2. Двойной клик — откроется в браузере по умолчанию.
3. Требования: любой современный браузер (Chrome, Edge, Firefox, Яндекс). Интернет не нужен.

### Вариант Б. LAN-сервер через батник (Windows)

1. Распакуй `MathArt LAN-сервер.zip` в обычную папку (правой кнопкой → «Извлечь всё»).
2. Запусти **`Запустить MathArt.bat`**.
3. При первом запуске батник:
   - проверит наличие Node.js; если его нет — **скачает и установит Node.js LTS v22 автоматически** (потребуется нажать «Да» в окне разрешения);
   - скачает зависимости игры (`npm install`, 1–3 минуты, дальше запуск мгновенный);
   - откроет браузер на `http://localhost:5173/` и поднимет сервер.
4. **Игра с друзьями в одной сети:** друзья открывают в браузере адрес из строки **`Network`** окна батника (вида `http://192.168.x.x:5173/`), жмут «Сетевая игра (LAN)» → «Войти по коду комнаты» и вводят код комнаты с твоего экрана. Коды WebRTC не нужны.
5. Чтобы закрыть игру — закрой окно батника.

> Окно батника не закрывай во время игры — это и есть сервер.

### Вариант В. Ручной запуск (Linux, macOS, Windows с Node.js)

```bash
cd MathArt            # папка с package.json
npm install           # первый раз, 1–3 минуты
npm run dev -- --host # сервер на http://localhost:5173
```

Для продакшн-сборки статики: `npm run build` → готовое в `dist/`.

### Требования

- **Node.js 20.19+ или 22.12+** (рекомендуется LTS 22 — его и ставит батник). Vite 7 на старых версиях Node не стартует.
- Браузер с поддержкой Canvas и WebSocket — любой актуальный.

## 3. Как играть

### Режимы (главное меню)

- **◎ РАЗМИНКА (СОЛО)** — тренировка: по полю расставлены мишени, цель — поразить как можно больше. Идеально, чтобы понять, как ведёт себя кривая.
- **▶ HOT-SEAT** — 2–6 игроков за одним экраном. Ходы по очереди, уравнение вводит тот, чья очередь, и передаёт устройство следующему.
- **⇄ СЕТЕВАЯ ИГРА (LAN)** — до 6 игроков по сети. Хост создаёт лобби и получает **код комнаты** (в простом режиме через сервер хоста); гости вводят его у себя. Если компьютеры в разных сетях — доступен ручной обмен кодами подключения (WebRTC: гость копирует код-предложение хосту, хост отвечает кодом-ответом). При жёстком NAT для WebRTC в настройках игры можно указать свой TURN-сервер.

### Ход игры

1. В свой ход введи уравнение в поле «Уравнение выстрела», например `y=0.5*x^2`.
2. Выбери направление полёта: ◀ ВЛЕВО / ВПРАВО ▶ (для уравнений вида `x=f(y)` — ▲ ВВЕРХ / ▼ ВНИЗ).
3. Предпросмотр покажет траекторию и точку финиша. Нажми **ОГОНЬ**.
4. Пуля летит по графику. Попадание в игрока отнимает 1 жизнь (по умолчанию), попадание в препятствие — взрыв (или пробитие/разрушение — по настройкам).
5. Побеждает последний выживший (или последняя выжившая команда в командном режиме).

### Язык формул

Поле принимает `y=f(x)` или `x=f(y)`. Доступны (полный список — в «Справка» в игре):

- Тригонометрия: `sin(x) cos(x) tan(x)` и гиперболические;
- Степени и корни: `x^2`, `sqrt(x)`, `cbrt(x)`, `pow(x,3)`;
- `abs(x)`, `sign(x)`, `floor(x)`, `ceil(x)`, `round(x)`;
- `exp(x)`, `log(x)`, `ln(x)`, `log2(x)`, `log10(x)`;
- `min(a,b)`, `max(a,b)`, `mod(x,5)`;
- Константы: `pi`, `e`, `tau`;
- Есть переключатель **∑ LaTeX** — можно писать `y=\frac{1}{2}x^{2}+3`.

Примеры рабочих выстрелов:

| Уравнение | Эффект |
|---|---|
| `y=0.5*x` | прямая насквозь |
| `y=0.08*x^2` | парабола через танк — обстрел «над горкой» |
| `y=6*sin(0.25*x)` | волна — обход препятствий |
| `y=1/(x-5)` | гипербола с асимптотой — резкий уход в сторону |
| `x=3` | вертикальный выстрел (ось x) |

### Режим «мультиточки» (настройка «Точек у игрока: 2–3»)

Как в GraphWar: у каждого игрока по несколько случайно расставленных точек-танков — два игрока по 3 точки выглядят на поле как матч 3 на 3. Ход остаётся у игрока, но в начале каждого своего хода ему случайно (но всегда другая, чем в прошлый раз) выбирается точка, от которой он будет стрелять — она подсвечена пульсирующим кольцом, остальные его точки приглушены. **Жизни у каждой точки отдельно** («Попаданий до смерти» — на точку): подбитая точка исчезает, а игрок продолжает воевать с оставшихся; проигрывает, когда подбиты все его точки. Сердечки в панели показывают суммарные жизни. Хорошо сочетается с отбросом (при попадании убегает именно зацепленная точка), пробитием и командными режимами. Работает и в соло-разминке: каждый выстрел — с новой случайной точки по мишеням.

### Точка отсчёта кривой (настройка лобби «Логика стрельбы»)

- **Zero point** (по умолчанию, новый метод): ноль в твоём танке, `x` отсчитывается от него. Кривая всегда проходит через тебя, сдвиг по горизонтали — через аргумент: `f(x−a)`.
- **GW point** (старый метод): `x` — абсолютная координата карты, кривая вертикально сдвигается так, чтобы проходить через тебя. Удобен, если привык считать координаты по сетке карты.

## 4. Настройки лобби (все пункты)

Настройки сохраняются в браузере автоматически — при следующем заходе всё на месте.

**— Карта и ход**

- **Размер карты** — ширина×высота поля в условных единицах (сетка на экране).
- **Таймер хода, сек** — 0 без лимита; по истечении ход автоматически переходит (пас).
- **Разброс спавна игроков, %** — насколько далеко друг от друга появляются танки.
- **Попаданий до смерти** — сколько жизней (1–5).
- **Точек у игрока (1–3)** — режим «GraphWar»: у каждого игрока N случайно расставленных точек; каждый ход стрельба идёт от другой случайной точки. Жизни у каждой точки: подбитая исчезает, игрок стреляет с оставшихся; умирает, когда подбиты все (подробности — в разделе «Как играть»). Работает и в соло.
- **Режим матча** — «Каждый сам за себя», «2 на 2» (ровно 4 игрока), «3 на 3» (ровно 6). В командном режиме игроки 1 и 3 (и 5) — команда 1, остальные — команда 2, огонь по своим отключён.
- **Предпросмотр траектории** — показывать кривую до выстрела.
- **Предсказание точки финиша** — метка, где пуля закончит полёт (стена/препятствие/игрок).

**— Ограничения кривых**

- **Лимит колебаний на ед. длины** — запрещает «пилу» из сотен витков на одном отрезке (0 — без лимита). Полезно против лагов от вычислительно тяжёлых формул.
- **Зацикленные маршруты** — разрешить замкнутые петли (эллипсы, окружности вида `y=sqrt(25-x^2)`-пары и т.п.).
- **Проверка достижимости спавнов** — гарантия, что каждый игрок появляется в точке, до которой можно достать хотя бы одним выстрелом.

**— Логика стрельбы**

- **Точка отсчёта кривой** — Zero point / GW point (см. раздел «Как играть»).

**— Попадания**

- **Игроков поражает пуля (1–6)** — пробитие. `1` — классика: взрыв после первого попадания по игроку. `2–5` — пуля прошивает до N игроков на пути. `6` — поражает всех на линии. В любом режиме пуля взрывается о препятствие и о стену карты.
- **Отброс при попадании** — живой игрок после попадания мгновенно смещается на случайную свободную клетку (не в препятствие, не вплотную к другим). Работает только когда «Попаданий до смерти» больше 1: с последним выстрелом умирают на месте.
- **Радиус побега, клеток (1–10)** — максимальное расстояние отброса. В сетевой игре точка побега одинакова у хоста и гостей.

**— Чат и история**

- **Чат в матче** (сетевой режим), **список предыдущих уравнений игрока / всех** — подсказки по уже использованным формулам.

**— Препятствия**

- **Препятствия на карте** — включить/выключить.
- **Разрушаемость объектов:**
  - *Отключена* — пуля останавливается о препятствие;
  - *Частичная* — разрушается с трёх попаданий, повреждённые подсвечиваются;
  - *Полная* — разрушается с одного попадания;
  - *Прогрызание* — пуля бурит отверстия: сквозной проём получится, если попасть в одно место несколько раз; сам объект остаётся.
- **Типы препятствий** — по каждому типу задаётся количество и размер (круги, квадраты, фигуры).

## 5. Своя музыка (только LAN-версия)

1. Положи аудиофайлы в папку **`MathArt/music/`** рядом с батником (внутри распакованного архива).
2. Поддерживаемые форматы: **mp3, ogg, wav, m4a, flac**.
3. Перезапуск не нужен — сервер подхватывает треки сразу. Твои треки играют **первыми** в ротации, затем встроенные.
4. Музыка звучит у **всех** подключённых игроков — файлы раздаёт твой сервер.

В одиночном `MathArt.html` эта функция недоступна по техническим причинам (файл ничего не может раздавать по сети) — игра просто играет встроенные треки.

## 6. Если что-то пошло не так

### Батник

| Проблема | Решение |
|---|---|
| «Node.js не найден» и автоустановка не сработала | Установи Node.js вручную: <https://nodejs.org> → кнопка LTS → перезапусти батник |
| «Не удалось скачать Node.js» / зависание на скачивании | Проверь интернет и прокси. Если антивирус/брандмауэр блокирует curl — разреши или качай установщик вручную по ссылке выше |
| «Не удалось скачать зависимости» при `npm install` | Проверь интернет, отключи VPN/прокси, проверь, что антивирус не режет доступ npm к реестру. Затем удали папку `node_modules` в `MathArt/` и запусти батник заново |
| После `npm install` вылезло «13 vulnerabilities (2 low, 2 moderate, 9 high)» | **Это нормально.** Предупреждения относятся к инструментам разработки, игра работает в локальной сети. **`npm audit fix` не запускай** — можно сломать сборку |
| Окно батника сразу закрывается | Запусти через командную строку (`cmd`), чтобы увидеть ошибку: перетащи батник в окно cmd и нажми Enter |
| Батник открывается как текст в Блокноте | Сломана ассоциация `.bat`. Правый клик → «Открыть с помощью» → «Интерпретатор команд Windows»; или запусти из cmd |
| Батник показывает кракозябры | Системная кодовая страница не CP866 — это не влияет на работу, только на отображение. Либо выполни в cmd: `chcp 866` и запусти заново |
| Антивирус ругается на батник | Ожидаемо: самописный скрипт, скачивающий Node.js. Батник текстовый — можешь открыть в Блокноте и проверить |

### Сервер и подключение

| Проблема | Решение |
|---|---|
| «Порт 5173 занят» / сервер не стартует | Другой процесс держит порт. Закрой лишние окна терминалов/IDE или перезагрузи ПК. Либо запусти вручную на другом порту: `npm run dev -- --host --port 3000` (батник всегда использует 5173) |
| Браузер открылся, но страница пустая/крутится | Подожди 5–10 секунд (первая сборка) и нажми F5. Если не помогло — смотри окно батника, сервер должен показывать `Local: http://localhost:5173/` |
| Windows спросил «Разрешить доступ?» при запуске | Нажми «Да» — иначе друзья не подключатся (сервер должен слушать сеть) |
| Друг не может открыть `http://192.168.x.x:5173` | Проверь: (1) оба в одной сети; (2) друзья берут IP из строки **Network** окна батника, а не `localhost`; (3) Wi-Fi роутер не изолирует клиентов (гостевая сеть/«изоляция» — отключи); (4) брандмауэр разрешил Node.js |
| Всё равно не видит сервер | Проверь пинг: друг в cmd пишет `ping <твой IP>`. Не пингуется — сеть изолирует (см. выше). Пингуется, но страница не открывается — порт блокирует брандмауэр: «Панель управления → Брандмауэр → Разрешение приложений» → разреши Node.js для частной сети |
| Код комнаты не принимается / «room-exists» | Страница хоста обновлена старая? Обнови у хоста F5 и создай комнату заново |
| Ручной обмен кодами WebRTC не соединяется | Устройства в разных сетях за жёстким NAT. В настройках игры укажи TURN-сервер (например, бесплатный на metered.live: там копируется URL с apiKey и вставляется в поле «TURN» в настройках). Либо проще — играйте через LAN-режим в одной сети |
| Гости подключились, но рассинхрон | У всех должна быть одна и та же версия игры. Обнови страницу у всех (F5) и начни матч заново |

### Игра

| Проблема | Решение |
|---|---|
| Музыка не играет | Браузеры блокируют автовоспроизведение: кликни один раз по странице. Треки из `music/` играют только в LAN-версии и только если положить их **до** запуска батника (или просто подожди — ротация подхватит их без перезапуска) |
| Кривая «уходит в неопределённость» | Функция не определена в точке танка (например `sqrt` отрицательного числа) или первый же шаг уходит за карту. Смести аргумент: `y=1/(x-5)`, `y=sqrt(x+30)` |
| «Превышен лимит колебаний» | Формула пилит слишком часто (высокочастотный синус и т.п.). Снизь частоту или увеличь лимит в настройках лобби |
| Игра подтормаживает | Закрой лишние вкладки с тяжёлыми сайтами; проверь, что в браузере включено аппаратное ускорение (настройки → система) |
| Сбросились настройки | Они хранятся в браузере (localStorage). Чистка куки/сайт-данных сбрасывает их; в сетевой игре настройки берутся у хоста лобби |

## 7. Для разработчиков

- **Стек:** React 19, TypeScript ~5.9, Vite 7, Tailwind CSS 3.4, mathjs (парсер формул), WebSocket (`ws`) для LAN-релея.
- **Сетевая игра:** два транспорта — WebSocket-релей прямо на dev-сервере хоста (простой режим, код комнаты) и WebRTC с ручным обменом SDP-кодами (fallback). Позиции танков не рассылаются: гости детерминированно повторяют выстрелы хоста, поэтому состояние мира сходится без рассинхрона.
- **Ключевые модули:** `src/game/trajectory.ts` — построение полёта, коллизии, пробитие и отброс; `src/game/render.ts` — отрисовка сцены и «прогрызание» отверстий; `src/game/parser.ts` — уравнения; `src/game/music.ts` — музыкальный движок; `music-plugin.ts` / `relay-plugin.ts` — middleware Vite (своя музыка и комнаты).
- Команды: `npm run dev` (разработка), `npm run build` (сборка), `npm run preview` (просмотр сборки), `npm run lint`.

Удачной стрельбы по параболам!
